# Student Performance Analytics

## Introduction
This project is about analyzing student performance. We have used student marks data to understand how students are performing in different subjects.

## About the Dataset
The dataset contains student marks, attendance, and other details. File name is student_performance_report.csv

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- Google Colab

## What we did in this project
- Collected student data
- Cleaned the data
- Analyzed marks subject wise
- Found out which students need improvement

## Files
1. student_performance_report.csv - dataset
2. Student-perfomance-analytics.ipynb - main code file

## How to run
- Open the ipynb file in Jupyter Notebook or Colab
- Run the cells one by one

## Conclusion
This project helps teachers and students to know the performance and improve in weak subjects.
